# /lootmanager

## Syntax

<!--cmd-syntax-start-->
```eqcommand
/lootmanager [pause on|off]
```
<!--cmd-syntax-end-->

## Description

<!--cmd-desc-start-->
Simple controls for MQ2LootManager. Status, pause and on/off. 
<!--cmd-desc-end-->

## Options

`pause [on|off]`
:   Will either pause or unpause as indicated by the users input. If neither `[on|off]` is chosen, it will toggle the setting.
    
    `[no option]`
    :   Will toggle the setting state.
    
    `[on]`
    :   Will turn pause on.
    
    `[off]`
    :   Will turn pause off.

No arguments will tell you the status of pause.
